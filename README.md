# Squeek Rush

squeekchain-project: 8b6eca1f-155b-4684-a5b4-004fb9d1475e
Squeek Rush is a small browser-based hamster sprint prototype. Players start a race, use BOOST (or the Space key), and compete against two computer-controlled rivals.

## Current status

- [x] Standalone browser game prototype
- [x] Keyboard and button boost controls
- [x] Race timer and local win counter
- [ ] Squeekchain network integration
- [ ] Verified on-chain or network-backed game data
- [ ] Squeekchain project verification

**Important:** This repository currently contains a standalone prototype. It is not yet integrated with Squeekchain and is not an official Squeekchain product or endorsement. Do not treat local wins as on-chain results or proof of network activity.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.
